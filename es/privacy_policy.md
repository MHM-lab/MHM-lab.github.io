En esta página se explica qué ocurre con sus datos cuando visita este sitio web.

## Datos que recopilamos
No recopilamos, almacenamos ni tratamos ningún dato personal. El sitio web no tiene formularios de contacto, cuentas de usuario ni funciones de comentarios.

## Cookies, análisis y seguimiento
Este sitio web no instala cookies ni utiliza herramientas de análisis o seguimiento (p. ej., Google Analytics).

## Alojamiento
El sitio web está alojado en GitHub Pages, un servicio de GitHub, Inc. Cuando visita el sitio, GitHub puede guardar en los registros de sus servidores información técnica, como su dirección IP, por motivos de seguridad y de funcionamiento. Para más detalles, consulte la [Declaración de privacidad de GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## Enlaces externos
Las páginas de este sitio web contienen enlaces a otros sitios (p. ej., revistas, universidades, redes sociales). Cuando sigue uno de estos enlaces, se aplican las políticas de privacidad de esos sitios.

## Sus derechos
De acuerdo con el RGPD, tiene derecho a solicitar información sobre sus datos personales, así como su rectificación y supresión.
